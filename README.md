# Theme Editor
A theme editor for a theme.json format im working on.

## Format
```json
{
  "displayName": "MyTheme",
  "author": "Me",
  "description": "My theme is about colors.",
  "primaryColors": [
    {
      "fill": "0xF07C59",
      "outline": "0xEB6958"
    },
    {
      "fill": "0xFF774F",
      "outline": "0xE35946"
    }
  ],
  "secondaryColors": [
    {
      "fill": "0xE09363",
      "outline": "0xE5785A"
    },
    {
      "fill": "0xE78267",
      "outline": "0xE15F3B"
    }
  ],
  "disabledColor": {
    "fill": "22, 22, 22",
    "outline": "19, 19, 19"
  },
  "backgroundColor": {
    "fill": "20, 20, 20",
    "outline": "22, 22, 22"
  },
  "textColor": "220, 220, 220",
  "type": "GRADIENT"
}
```
